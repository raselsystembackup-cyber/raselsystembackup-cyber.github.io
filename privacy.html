Privacy Policy

ERP SYSTEM BACKUP

Effective Date: 26 November 2026

1. Application Purpose

ERP System Backup is a privately managed application intended for authorized business backup and disaster recovery operations.

2. Google User Data

The application requests Google Drive access to upload, retrieve, verify and manage authorized backup files. Access may include file contents, file names, folder information and file metadata.

3. Use of Information

Google user data is used solely for authorized backup, recovery, integrity verification and backup retention management.

4. Data Storage and Security

Backup files are intended to be encrypted before upload and stored in a restricted Google Drive account. Authentication credentials must be stored securely and access must be limited to authorized operators.

5. Data Sharing

Google user data is not sold, used for advertising, or used to train artificial intelligence models. Data is not disclosed to unauthorized third parties.

6. Data Retention and Deletion

Backup files are retained according to the configured backup retention schedule. Authorized operators may delete backup files directly from Google Drive and remove locally stored copies when no longer required.

7. Revoking Access

The account owner may revoke application access at any time through Google Account Connections. Revoking access stops authorized future Google Drive operations but does not automatically delete existing backup files.

8. Google API Compliance

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
